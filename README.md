# HELBDrone 🚀

HELBDrone is a 2D aerial combat game developed in Java using JavaFX as part of an academic Programming III project.

The player controls a futuristic Sentinel ship sent to explore the abandoned planet Epsilon-7. The objective is to fight an AI-controlled aerial base that continuously deploys combat drones with different movement strategies.

## 🎮 Features

- Player movement and shooting system
- Four enemy drone types with different behaviors
- Projectile and collision system
- Player and enemy health management
- Four progressive difficulty levels
- Temporary invincibility power-ups
- Collectable homing missile
- Teleportation system
- Dynamic clouds that hide game elements
- Enemy base vulnerability system
- Score calculation and CSV score saving
- Keyboard commands for testing game mechanics

## 🛠️ Technologies

- Java
- JavaFX
- Object-Oriented Programming
- File handling / CSV
- Git & GitHub

## 🎯 Objective

Destroy the enemy drones to make the aerial base vulnerable and attack it before new drones are deployed. Complete all four levels while surviving enemy attacks and achieve the best possible score.
